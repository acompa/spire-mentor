Reward and return: self-test

Answer each question from memory and in writing before you open any answer. Come back in a few days and answer them again.

The questions cover Chapter 3: Reward and return.

Recall questions

  1. A reward and a supervised-learning label are both numbers attached to an example. What does a label tell you that a reward does not? Why can a won run still contain bad decisions?

    Answer

    A label gives the correct output for an example. A reward only grades how a step turned out, after the fact, and says nothing about which action would have been right. A reward is also one part of a sum over many steps, so a single number at the end of a run covers hundreds of decisions. A run that won can contain bad decisions, and a run that died can contain good ones. Chapter 5 trains the policy on a log-likelihood weighted by advantages, which come from returns, not on the chosen actions as targets.

    (Sections 1 and 10)

  2. Instinct's per-step reward is the change in two counters plus a win term, Equation (4) in the chapter. Explain why, with \(\gamma = 1\), the return of a whole run depends only on the counters at the end. Then say what the expected return splits into.

    Answer

    Each step pays \[R_F[F(s_{t+1}) - F(s_t)] + R_B[B(s_{t+1}) - B(s_t)],\] plus \(R_W W\) on the last step. When you add these with \(\gamma = 1\), each bracket cancels against the next one, so only the last counter value minus the first remains. Every run starts on floor 0 with no bosses paid, so \(G_0 = R_F F_T + R_B B_T + R_W W\). Taking the expectation gives \[J(\theta) = R_W \Pr(\text{win}) + R_B\,\mathbb{E}[B_T] + R_F\,\mathbb{E}[F_T].\] In words, maximising the return means maximising the win rate, with a little credit for how far the run got.

    (Section 2)

  3. Why is the return also called the reward-to-go? A decision made on floor 20: what credit does \(G_t\) give it for the floors the run already climbed?

    Answer

    \(G_t\) sums only the rewards from step \(t\) to the end of the episode. Rewards earned before step \(t\) are left out. With \(\gamma = 1\), \(G_t = G_0 - \sum_{k \lt t} r_k\), so the floor-20 decision gets no credit for the floors already climbed. Splitting off the first term gives the recursion \(G_t = r_t + \gamma G_{t+1}\) with \(G_{T+1} = 0\), which the value methods of Chapter 4 build on.

    (Sections 2 and 10)

  4. A sparse reward causes two separate problems. Name both. For the first one, explain why the policy gradient is exactly zero when a random policy plays under a win-only rule, and say what the 300 rescored random runs showed.

    Answer

    The first problem is that the learner gets no signal. The policy gradient weights each action's log-probability by roughly \(G_0 - b\). If the policy never wins, every return is 0, the average-return baseline is 0, every weight is 0, and the gradient is exactly zero. The 300 random runs rescored under the win-only rule all had return 0. Under Instinct's rule all 300 had a nonzero return, with mean 0.0038 and standard deviation 0.0026, so a gradient exists but is weak next to a win worth 1.0. The second problem is that the signal is weak and far away: the reward at step 700 has to be credited back to an early card choice, and every step in between adds noise.

    (Sections 3 and 9)

  5. Potential-based shaping pays \(\tilde r_t = \gamma\Phi(s_{t+1}) - \Phi(s_t)\). Walk through why this keeps the best policy the best. What did Wiewiora add, and what does that say shaping can and cannot change?

    Answer

    Summed along an episode with discount \(\gamma^t\), the shaping terms telescope: every middle potential appears once with a plus and once with a minus. The total is \(\gamma^{T+1}\Phi(s_{T+1}) - \Phi(s_0)\). If every terminal state has potential 0, the shaped return is \(G_0 - \Phi(s_0)\). The start state does not depend on the policy, so every policy's expected return moves by the same amount. Wiewiora showed that a Q-learner with potential-based shaping makes the same updates as one without shaping whose Q-table starts at \(Q_0(s,a) + \Phi(s)\). Shaping is a prior on the value function. It changes where learning starts, not where it ends, so it can only change the speed of learning.

    (Section 4)

  6. The chapter gives a two-part test for any reward term. State both conditions. Why must the terminal potential be exactly 0 when \(\gamma \lt 1\), when a shared constant is enough with \(\gamma = 1\)?

    Answer

    The form condition: the term must equal \(\gamma\Phi(s_{t+1}) - \Phi(s_t)\) for one function \(\Phi\) of the state. A term that depends on the action, or on anything outside the state, fails. The ending condition: with \(\gamma = 1\), every terminal state must have the same potential. With \(\gamma = 1\) a shared constant adds the same amount to every return. With \(\gamma \lt 1\) a constant \(c \ne 0\) adds \(\gamma^{T+1} c\), which depends on the episode length and so on the policy. The form condition also stops loop farming: with \(\gamma = 1\), a loop \(s \to s' \to s\) collects 0.

    (Section 4)

  7. The chapter reads the discount \(\gamma\) three ways. Give all three. For the third, what is the effective horizon at \(\gamma = 0.99\), and what would that discount do to Instinct's win seen from the first decision?

    Answer

    First, as a preference for sooner reward, as with interest. Second, as a chance of stopping: if the episode is cut off with probability \(1 - \gamma\) after each step, the expected undiscounted sum equals the discounted sum. Third, as a horizon: the weights sum to \(1/(1-\gamma)\), about 100 steps at \(\gamma = 0.99\). With \(T = 678\), the median index of the last decision in the network's won runs, the win is worth \(0.99^{678} \approx 0.0011\) from the first decision. That is less than one 0.002 floor reward. At \(\gamma = 0.999\) it would be worth 0.51.

    (Sections 5 and 9)

  8. Practitioners often discount episodic tasks anyway. What do they gain and what do they pay? How does Instinct get the gain without paying that price?

    Answer

    A shorter horizon gives a less noisy return. A sum of 700 random rewards has more variance than one that effectively sums 100, and value methods converge faster. The price is bias: the agent optimises a different objective from the one you care about. Instinct keeps \(\gamma = 1\), so a win is worth exactly 1.0 from every decision. It controls variance with the λ of GAE instead. λ biases the gradient estimate when the critic is wrong, but it leaves the objective unchanged.

    (Sections 5 and 7)

  9. What is reward hacking? Use it to explain why Instinct pays nothing for HP, and say what evidence the plan cites.

    Answer

    Reward hacking is when the optimiser finds a cheap way to raise the reward that is not what the designer intended. It does not need a bug. Under Goodhart's law, a quantity that tracks the goal in normal play stops tracking it once it is optimised directly. HP usually comes with winning, but the strongest play sometimes spends HP to win more often, so an HP term would push the agent away from that play. The plan cites AlphaDefect: its stronger checkpoint entered the act-1 boss with 9pp less HP and won more. The plan also lists "the hybrid's suspected cap" as a second reason. The chapter could not check either citation, because the evidence sits in a knowledge base outside the public repository.

    (Sections 6 and 8)

  10. Instinct departs from the textbook setup in four ways. Pick two of these and explain each: rewards that arrive during forced steps, and the reason the value output stays in 32-bit floats.

    Answer

    The engine takes forced steps that the agent never sees, such as moves with one legal action and the end of a fight. Reward from those steps collects in _pending_r, and _assign_pending credits it to the most recent stored decision. The run's total stays the same. Only the bookkeeping moves. For precision: adjacent bfloat16 numbers are 0.0039 apart just below 1.0 and 0.0078 apart just above it, where a won state's value of about 1.24 sits. Both gaps are wider than the 0.002 floor reward, so a bfloat16 value head could not tell one more floor from rounding error. The other two departures are the pre-registered reward and \(\gamma = 1\) with λ for variance.

    (Sections 7 and 8)

  11. The floor term pays the change in a high-water mark. Which of the two shaping conditions does it pass, which does it fail, and what is its net effect on the return?

    Answer

    It passes the form condition. With \(\Phi_F(s) = R_F F(s)\) and \(\gamma = 1\), the term is exactly \(\Phi_F(s_{t+1}) - \Phi_F(s_t)\), and a high-water mark is a function of the state, so no loop can farm it. It fails the ending condition. At the terminal state the counter keeps its final value, so the terminal potential is 0.036 for a death on floor 18 and 0.092 for a win on floor 46. Splitting the term shows a potential-based part that sums to 0 plus a terminal bonus \(R_F F_T\). The boss term behaves the same way. The net effect is a terminal reward for progress, \(R_F F_T + R_B B_T\), added to the win, which can change which policy is best.

    (Sections 4 and 8)

  12. What did the measured runs show about where the network's return comes from, and about HP? Then answer the confusion "if HP earns nothing, the agent ignores HP".

    Answer

    The network won 243 of 300 runs. Of its mean return of 1.039, the win supplied 0.810, or 78%, bosses 0.140 and floors 0.089. Only 7.0% of its decisions carried any reward. Won runs ended with anywhere from 10% of maximum HP up, the middle 80% between 28% and 86%, and every one scored the same return. The agent ignores HP as a goal, not as a means. HP is part of the state, and when HP helps the agent win, states with more HP have higher value. The critic's value estimate, not the reward, is where HP gets a price.

    (Sections 9 and 10)

Calculations

  1. A run reaches floors 1 through 18, beats the act-1 boss on floor 16, and dies on floor 18. Use \(R_F = 0.002\), \(R_B = 0.05\), \(R_W = 1\) and \(\gamma = 1\). Compute \(G_0\). Then split the floor part into the potential-based part and the terminal progress bonus, and give the value of each.

    Answer

    The counters at the end are \(F_T = 18\), \(B_T = 1\) and \(W = 0\).

    \[G_0 = 0.002 \times 18 + 0.05 \times 1 + 1 \times 0 = 0.036 + 0.05 + 0 = 0.086.\]

    The potential-based part uses \(\hat\Phi_F\), which is 0 at the terminal state and 0 at the start. It telescopes to \(\hat\Phi_F(s_{T+1}) - \hat\Phi_F(s_0) = 0 - 0 = 0\).

    The terminal progress bonus is \(R_F F_T = 0.002 \times 18 = 0.036\). It carries the whole floor part of the return.

    HP at death, elites fought, and deck strength do not change any of these numbers.

    (Sections 2 and 8)

  2. Use the network's measured values \(p = 0.81\) and \(m_L = 0.174\), and the 0.242 progress every standard win collects. A policy gives up one percentage point of win rate, \(\Delta p = 0.01\). How much extra progress \(\Delta m_L\) per lost run must it collect to break even, to first order and by the exact condition? Convert the first-order answer to floors.

    Answer

    Start from \[J = p\,(R_W + 0.242) + (1-p)\,m_L.\] Break-even to first order needs \[(1-p)\,\Delta m_L = \Delta p\,(R_W + 0.242 - m_L).\]

    The right side is \[0.01 \times (1.242 - 0.174) = 0.01 \times 1.068 = 0.01068.\]

    First order: \(\Delta m_L = 0.01068 / 0.19 \approx 0.056\).

    Exact: replace \(1 - p\) with \(1 - p + \Delta p = 0.20\), so \(\Delta m_L = 0.01068 / 0.20 \approx 0.053\).

    In floors: \(0.056 / 0.002 = 28\) more floors per lost run, or roughly one more boss at 0.05. The progress bonus can break a near-tie between policies, but it cannot pay for a real loss of win rate.

    (Section 8)
